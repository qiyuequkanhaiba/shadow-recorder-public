# F1 修复后

## 改动

每次区域截图按当前 `screen.getAllDisplays()` 新建选区窗口，一块屏幕一个窗口，位置和大小等于该屏的 `bounds`。不再复用上一张窗口。

选区换成物理像素时，用这个窗口记下的 `scaleFactor`，原点用 `screen.dipToScreenPoint(窗口原点)`。不拿一个全局比例去乘整张虚拟桌面。

`windowSelectionAtClientPoint` 和 `confirmAreaSelection` 用发起 IPC 的 `event.sender` 找到对应窗口。每个窗口单独走 `bindTrustedDataDocument` 和导航拦截；HTML 末尾加了唯一注释，关闭时只撤销自己的 data URL。

截完以后，标注留在发起选区的那块屏上，其它屏的选区窗口关掉。跨两块屏的选区没有做。

倒计时截图和钉图的流程没改。

## 手工复测

虚拟机仍然只有一块屏：`1199×770`，桌面 DPI `96`。下面三组没有在虚拟机里点：

| 组 | 能否在两块屏任意位置选区 | 截图像素 |
| --- | --- | --- |
| 两屏都是 100% | 未测。虚拟机没有第二块屏 | 未测 |
| 主屏 100%、副屏 150% | 未测 | 未测 |
| 截一次后改副屏缩放或拔掉副屏 | 未测。每次按下都会按当前显示器列表重建窗口 | 未测 |

单屏、倒计时和钉图也没有在界面上重新点。单屏时窗口数等于当前显示器数，选区坐标相对该窗口。
