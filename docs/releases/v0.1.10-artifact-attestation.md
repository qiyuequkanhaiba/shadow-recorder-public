## Privacy Version Boundary

This artifact matches the public source commit above, not the current `main`
branch. It predates the public-main change that makes semantic plaintext capture
an explicit opt-in. When semantic recording is enabled in this v0.1.10 build,
non-password semantic text may be captured according to its configuration.
Password fields remain redacted. Do not describe v0.1.10 as having the current
privacy-first plaintext default; users requiring that default must build a
later public-source revision and use an installer made from it.
