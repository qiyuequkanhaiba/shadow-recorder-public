# ReqCase Shadow Recorder v0.1.10

## Windows x64 Installers

- `ShadowRecorder-Setup-0.1.10-x64.exe`
- `ShadowRecorder-0.1.10-x64.msi`

Verify the downloaded installers against the attached `SHA256SUMS.txt` before
installation. Both installers are unsigned: `osslsigncode 2.14` found no
Authenticode signature in either file.

## Privacy Version Boundary

These existing installers match public source commit
[`4f8355d8ae3e4e477025ee20cf4b1f415934c817`](https://github.com/qiyuequkanhaiba/shadow-recorder-public/commit/4f8355d8ae3e4e477025ee20cf4b1f415934c817),
not current `main`. They predate the later change that makes semantic plaintext
capture an explicit opt-in. When semantic recording is enabled, non-password
semantic text may be captured according to the installer configuration.
Password fields remain redacted. Do not treat v0.1.10 as the build with the
current explicit-opt-in plaintext default.

## 隐私版本边界

这些现有安装包对应公开源提交
[`4f8355d8ae3e4e477025ee20cf4b1f415934c817`](https://github.com/qiyuequkanhaiba/shadow-recorder-public/commit/4f8355d8ae3e4e477025ee20cf4b1f415934c817)，
而非当前 `main`。它们早于“语义明文采集必须显式启用”的后续改动。按安装包配置启用
语义记录时，可能采集非密码语义明文；密码字段仍会被脱敏。请勿将 v0.1.10 描述为采用
当前“必须显式启用明文采集”默认策略的构建。
