# v0.1.10 Release And Chinese README Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the existing v0.1.10 Windows installers with verified provenance and a Chinese README, without modifying application code or rebuilding artifacts.

**Architecture:** Keep source documentation, provenance evidence, and binary Release assets separate. Verify the exact local binaries first; update repository documentation and push it; then create a GitHub Draft Release, upload the verified files, inspect its rendered state, and publish it only when the attribution and privacy requirements are met.

**Tech Stack:** Git/GitHub Releases, checksum and PE-signature tools, archive inspection tools, Markdown, and the GitHub web UI when API credentials are unavailable.

## Global Constraints

- Preserve the ReqCase brand, `com.reqcase.shadowrecorder` app ID, and `reqcase:shadow-recorder:*` IPC namespace.
- Source code is MIT licensed; do not alter product implementation or rebuild either installer.
- State installer signature status truthfully. Never claim an unavailable verification result is signed.
- Attach exact FFmpeg license and notice material when FFmpeg is bundled. Stop publication if it cannot be recovered.
- State that v0.1.10 predates the explicit opt-in default for semantic plaintext capture.
- Never upload recordings, exports, diagnostics, credentials, private paths, or private repository references.
